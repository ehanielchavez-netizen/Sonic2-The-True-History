SONIC 2: THE TRUE HISTORY
Mod para Sonic 2 Absolute
Autor: Hanichav02
Version: 1.0
Fecha de lanzamiento: 2026-11-25


============================================================
QUE ES ESTE MOD
============================================================

Sonic 2: The True History es un mod de campana para Sonic 2 Absolute
1.1.1 Easy Setup. Reconstruye la aventura como una version de
historia alternativa de Sonic 2: las zonas perdidas sobrevivieron,
el orden de las eras cambio y todo el juego se convirtio en una
historia de viaje en el tiempo.

No es solo un cambio de colores ni un reskin. Cambia el Level Select,
el orden de las eras y la progresion, y agrega/importa zonas de otros
mods de la comunidad. Tambien agrega transiciones propias como el
Warp Point y Hidden Palace.

El mod se distribuye por separado. El juego base, su ejecutable y sus
archivos originales no estan incluidos.

============================================================
COSAS IMPORTANTES / SINCERAS
============================================================

- "Blue Ocean" es el nivel de Hydrocity con el nombre cambiado.
  Por dentro sigue siendo Hydrocity; no es un nivel nuevo desde cero.

- Rock World esta solamente en PRESENTE ARRUINADO. Se quito de
  PASADO para no tener la misma zona duplicada.

- Genocide City 1 usa el layout de Genocide City disponible en la
  fuente GCZ. Genocide City 2 no esta incluido en esta version.

- El Acto 2 de Genocide City usa el layout de la fuente GCZ e incluye
  un poste de meta para poder terminarlo. No es un Acto 2
  completamente original.

- Los Star Posts de Genocide City estan desactivados en la version
  1.0 por un bug de checkpoints. Los actos siguen siendo jugables.

- La ultima batalla usa el Death Egg original. No se incluyeron Death
  Egg extra, Gauntlet ni una arena con todos los jefes.

- Algunas zonas y assets vienen de otros mods. No todo el contenido
  fue hecho desde cero para este mod.

- Algunos scripts quedaron como "no-op" (por ejemplo, objetos de
  Hidden Palace que no tenian archivo original). No rompen el juego,
  pero esos objetos no hacen nada.

- Hay musica y variantes que se conservan porque el juego base o el
  Sound Test las usan, aunque un script del mod no las mencione.


============================================================
INSTALACION
============================================================

1. Tener Sonic 2 Absolute 1.1.1 Easy Setup.
2. Copiar la carpeta "S2TheRealHistory_1.0" dentro de:
   Sonic2Absolute_1.1.1_EasySetup\Mods\
3. Abrir el juego y activar el mod desde el menu de mods.
4. No sobrescribir los archivos base del juego:
   - Data\Game\GameConfig.bin
   - Scripts\LevelSelect\MenuControl.txt

El mod esta pensado para funcionar como una capa encima del base.
Haz una copia de seguridad de tus partidas antes de instalar o
actualizar.


============================================================
PROBLEMAS CONOCIDOS
============================================================

- Blue Ocean no es un nivel nuevo: es Hydrocity renombrado.
- Genocide City 2 no esta incluido.
- Los Star Posts de Genocide City estan desactivados en la 1.0 por
  un bug de checkpoints.
- El Acto 2 de Genocide City usa el layout disponible en la fuente
  GCZ.
- Olympus y Madness Mountain no son jugables por completo.
- Algunos niveles importados pueden tener detalles visuales o de
  sonido distintos a su version original.
- Si una zona se ve rara o no carga, revisar que el mod este activo y
  que los archivos base no hayan sido modificados.
