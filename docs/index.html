About the mod

Not a reskin. A different history.

Sonic 2: The True History reimagines Sonic 2 as an alternate timeline where the lost zones survived. The campaign is reordered into five connected eras, the Level Select is rebuilt, and the finale follows a new route through Sky Chase, Wing Fortress and the original Death Egg.

It also restores community-made zones such as Ocean Wind, Jungle Woods, Sand Shower, Tropical Sun, Blue Ocean, Rock World and Genocide City, and adds custom transitions including the Warp Point and Hidden Palace.

This is a fan project for Sonic 2 Absolute 1.1.1 Easy Setup. The mod is distributed separately: the base game, its executable and its original files are not included.

Read before playing

  • Blue Ocean is Hydrocity renamed, not a brand-new level.
  • Genocide City 2 is not included in version 1.0.
  • The finale uses the original Death Egg. No extra Death Egg, Gauntlet or all-boss arena.
  • Star Posts are disabled in Genocide City because of a checkpoint bug.
  • Some imported zones may look or sound different from their original releases.

Installation

Four steps to play.

The mod is a layer for Sonic 2 Absolute 1.1.1 Easy Setup. It does not include the base game and should not replace its core files.

  1. Get Sonic 2 Absolute

    Install a clean copy of Sonic 2 Absolute 1.1.1 Easy Setup first.

  2. Download v1.0

    Grab the latest release ZIP from the GitHub Releases page.

  3. Extract the mod folder

    Place S2TheRealHistory_1.0 inside Sonic2Absolute_1.1.1_EasySetup\Mods\.

  4. Enable it in-game

    Open the game, go to Mods, enable Sonic 2: The True History and restart if needed.

Do not overwrite base files

Keep Data\Game\GameConfig.bin and Scripts\LevelSelect\MenuControl.txt as they are. The mod is designed to work as an overlay.

Target folder Sonic2Absolute_1.1.1_EasySetup\ └─ Mods\ └─ S2TheRealHistory_1.0\

Back up your saves

This is a fan mod. Save compatibility between versions is not guaranteed, so keep a backup before updating.

Good to know

Frequently asked questions.

Straight answers about what is included, what is not, and how the mod is meant to be installed.

Is the base game included?

No. The repository and release ZIP contain only the mod. You need your own copy of Sonic 2 Absolute 1.1.1 Easy Setup.

Is Blue Ocean a new level?

No. Blue Ocean is Hydrocity with a new name and presentation. The level geometry is still Hydrocity.

Is Genocide City 2 included?

No. Version 1.0 includes Genocide City Act 1 and Act 2, but not a separate Genocide City 2 stage.

Why are Star Posts disabled in Genocide City?

The checkpoint system had a bug in this stage, so Star Posts are removed in 1.0. Act 2 received a goal post so the act can still be completed.

Can I stream or make videos with the mod?

Yes. Free streams, videos and reviews are welcome. Credit the mod and link back to the repository when possible.

Does it work on Android or other platforms?

Version 1.0 is tested with the Windows Easy Setup. Other platforms are not officially supported.
